# Natural ou Fake Natty? Origem do Bug na Era das IAs Generativas

## 📒 Descrição
Este projeto explora a origem do conceito de "bug" no mundo da computação, utilizando IAs generativas para criar conteúdo multimídia. O objetivo é mostrar como essas tecnologias podem transformar ideias em vídeos e textos criativos.

## 🤖 Tecnologias Utilizadas
- **Zeemo IA**: para gerar o vídeo explicativo sobre a origem do bug.
- **Copilot (Microsoft)**: para escrever o README e o roteiro do vídeo.
- **GitHub**: para hospedar e compartilhar o projeto.

## 🧐 Processo de Criação
1. Pesquisei sobre a origem do termo "bug" na computação.
2. Escrevi o roteiro com o auxílio do Copilot.
3. Usei o Zeemo IA para transformar o roteiro em vídeo.
4. Documentei todo o processo neste README para fortalecer meu portfólio.

## 🚀 Resultados
- Um vídeo explicativo sobre a origem do bug, criado com IA.
- Um README estruturado e pronto para ser compartilhado no GitHub.
- Experiência prática no uso de IAs generativas para produção de conteúdo.
